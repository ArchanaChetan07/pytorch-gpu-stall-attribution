# Results

**No hardware results yet.** Everything in this repository has been exercised on
synthetic traces only.

This file exists so that absence is stated in the obvious place rather than
inferred from its absence. When real numbers land they go here, and until then
nothing in this repository should be quoted as a measurement.

## What has been demonstrated

The pipeline runs end to end and the validation machinery works, on traces
generated by `whystall.synth`:

```bash
whystall demo --out demo/
```

Those traces are built by a model of how idle windows arise — a kernel starts at
`max(stream free, launch time + launch latency)`, and a host that runs too far
ahead is blocked by queue depth — so they exercise every rule and every scoring
path. They are not hardware, they contain no real dataloader, and the accuracy
figures the demo prints are a property of the model, not of the classifier's
performance on anything real. The demo says so in its own output.

## Standing caveats for whatever lands here

- **Precision is a lower bound.** A correct verdict on a stall the injection did
  not create has no ground-truth label and scores as a false positive. The
  control-versus-treatment shift is the number that answers the question;
  every report prints it.
- **The injected magnitude is not ground truth.** Prefetch depth absorbs part of
  any injection, so 5 ms of delay routinely yields 2 ms of idle. Ground truth is
  the labelled gap; the magnitude is only the sweep coordinate.
- **Synthetic-trace numbers must never appear alongside hardware numbers**
  without the distinction made in the same sentence.
